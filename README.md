# CV Job Matcher AI

An AI-powered recruitment system that analyzes CVs and job descriptions using semantic embeddings.

---

## Features

- Upload CV (PDF)
- AI semantic matching (Sentence Transformers)
- Score calculation with visualization
- Match level (High / Medium / Low)
- AI-generated remarks
- Modern React dashboard

---

##  Tech Stack

### Backend
- FastAPI
- Python
- Sentence Transformers (AI)
- pdfplumber

### Frontend
- React.js
- Circular Progress UI
